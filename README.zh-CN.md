我是李述博，做让人和 AI Agent 一起工作、不必交出数据所有权的工具。

大部分时间在做 **Mebular** —— 一个面向 AI 助手的分布式记忆与任务网络：一次记忆，所有助手，所有设备。

## 现在

记忆和任务留在你自己的设备上，设备之间直接同步。每次变更都有签名、事后可审计，并通过 MCP 暴露给助手。

- **本地优先** —— 没有托管账号，没有中心协调者
- **签名与可审计** —— 可验证的历史
- **设备直连同步** —— 你的设备彼此对话
- **开放接口** —— 通过 MCP 接入你已经在用的助手

## 做法

- **默认本地优先。** 云不在的时候，工具也应该能继续用。
- **把边界摊开。** 每一次同步、签名和变更都应该能被检查，而不是靠信任。
- **记忆属于你。** 助手了解你，不该以在别人服务器上开个账号为前提。
